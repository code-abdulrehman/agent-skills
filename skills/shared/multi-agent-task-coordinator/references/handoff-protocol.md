# Handoff protocol

Record the prior writer's session identity and verified status. A current-tree agent can be asked to stop at a safe boundary and interrupted with native agent control. A separate session requires its owner to pause it; process inspection or a quiet file timestamp alone does not prove that its model will not write again. Never terminate unrelated processes.

The handoff must state completed and pending work, modified and untracked files, tests actually executed with results, known failures, dependencies, files at risk of overlap, and one exact next implementation step. Preserve the source tree and empty index. Treat earlier test totals as historical until rerun.

The lead gives the handoff to the next assigned specialist before that workstream starts. The specialist inspects current implementation and tests, validates what remains, and continues only unfinished work. If the prior agent resumes or a new external writer appears, revoke affected write grants until ownership is restored.
